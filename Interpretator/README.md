## Язык SimpleSharpLang

### Возможности языка

#### Типы данных

Числовые
* int
* uint
* num (бесконечно большой не теряющий точности)

Символьные
* char
* string

Логические
* bool

Сложные (комплексные)
* struct
* type (под вопросом)

#### Операторы

Изменения
* \+ 
* \- 
* \* 
* /

Сравнения
* ==
* !=
* <
* \>

Присвоения
* =

#### Конструкции условий и циклов

Условия
* if else

Циклы
* while

#### Прочее

Поддерживается только кодировка UTF-8

### Идеи на будущее развитие языка

* Массивы и циклы для массивов
