# Список тестов для Lexer

## Идентификаторы и ключевые слова
- [ ] Ключевые слова типов: `int bool string char unit num struct`
- [ ] Ключевые слова значений логического типа: `true false`
- [ ] Ключевые слова условий, циклов, возврата: `if else while break continue return`
- [ ] Разбор идентификаторов: `hello h42 ab_44`
- [ ] Ключевые слова в ином регистре считаются идентификаторами: `IF eLse String`
- [ ] Идентификаторы, начинающиеся с цифр невалидны: `1Str`

## Литералы
### Целочисленные
- [ ] Целочисленные литералы: `12 0 0011`

### Символьные
- [ ] Символьные литералы содержат один символ, ESCAPE-последовательность или экранированный символ: `'c', '\t', '\''`
- [ ] Символьные литералы должны открываться и закрываться при помощи `'`: `'a`
- [ ] Символьные литералы не содержат 0 или несколько символов: `'', 'ab'`
- [ ] Символьные литералы не содержат более одной ESCAPE-последовательности или несколько экранированных символов: `'\r\n', '\'\'`

### Строковые
- [ ] Строковые литералы содержат любое число символов: `"", "a", "Hello, World!"`
- [ ] Строковые литералы могут содержать ESCAPE-последовательности или экранированные символы: `"Hello, \"User\"", "Bye!\n"`
- [ ] Строковые литералы должны открываться и закрываться при помощи `"`: `"Hello`

## Пробельные символы и комментарии
- [ ] Пропуск пробельных символов: `' ', '\t', '\r', '\n'`
- [ ] Пропуск однострочных комментариев: `// Hello, World!`

## Операторы, разделители и скобки
- [ ] `x + y - a * b / 4` - Арифметические операторы `+, -, *, /`
- [ ] `x > 4 && y < 7 || a == b || c != b` - Строгие операторы сравнения `>, <, ==, !=` и логические операторы `&&, ||`
- [ ] `x >= y || b <= 2` - Нестрогие операторы сравнения `>=, <=` и оператор `!`
- [ ] `if (arr[5] < 2){}` - Круглые, квадратные, фигурные скобки `(, [, ], ), {, }`
- [ ] `point.x = 7;` - Оператор присваивания `=`, оператор точка `.`
- [ ] `foo(5, 4);` - Разделитель `;`, разделитель `,`
